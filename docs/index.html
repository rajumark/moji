Why Moji

Built for a keyboard, not a datacenter

No server round trip means no latency budget, no API bill, and no user text ever leaving the phone. Everything runs in-process, in plain Kotlin.

No dependencies

Pure Kotlin inference — no ONNX Runtime, no TFLite, no native code. Nothing else to version-bump, conflict, or bloat your build. Adds about 5 MB to your APK.

Private & offline

The model ships inside the AAR. No network calls, no permissions, no telemetry — one less thing to explain in your privacy policy.

Fast

~0.5 ms per suggestion once warm on Apple silicon, ~2 ms on a mid-range phone. Fast enough to run on every keystroke, not just on submit.

22+ languages

Works across languages and scripts. Top-1 and top-5 predictions match a Python reference implementation exactly on all 443 test vectors.

Install

Add it to your build

One line in your Gradle file. Available now via JitPack — no waitlist, no API key.

JitPack live
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        mavenCentral()
        maven { url = uri("https://jitpack.io") }
    }
}

// build.gradle.kts
dependencies {
    implementation("com.github.rajumark:moji:v1.1.0")
}

Usage

Three lines to suggestions

Load once, reuse the instance, and call suggestions() on every keystroke — it's thread-safe and fast enough for it.

Kotlin
val moji = Moji(context)

val top = moji.suggestions("Pay my bills").first()
top.emoji   // "💰"

moji.close()
Java
try (Moji moji = new Moji(context)) {
    List<MojiSuggestion> s =
        moji.suggestions("Pay my bills");
}

API at a glance

MemberDescription
Moji(context)Loads the bundled model. Implements Closeable.
suggestions(text, limit = 8, skinTone = null)Best emoji first. Returns List<MojiSuggestion>.
MojiSuggestion(emoji, name, confidence, supportsSkinTone)One ranked result.
SkinTone.LIGHT … DARKApplied to people/hand emoji that support it. applyTo(emoji) is also public.

How devices are counted

A monthly active device is a phone, tablet or other device that runs Moji at least once in a calendar month.

The 10,000 limit applies separately to each product, each platform (Android, iOS, web…) and each Hoverfly model. Crossed it? You have 30 days to get a commercial license.

FAQ

Questions

What is Moji?

An Android library: give it a task or a message and it returns the emoji that fit, ranked by confidence, in 22+ languages.

Does Moji run on device?

Yes. Inference happens entirely on-device in plain Kotlin — no server call, no network permission, no telemetry.

Which platforms does Moji support?

Android, minSdk 21, from both Kotlin and Java.

How accurate is it?

Top-1 and top-5 predictions match a Python reference implementation exactly on all 443 test vectors across every supported language, with a maximum numerical difference of about 0.0000024 between the two.

How fast and how big is it?

About 0.5 ms per suggestion once warm, and about 5 MB added to your APK for the model and tokenizer.

How much does Moji cost?

Nothing for products with up to 10,000 monthly active devices per platform, including commercial apps. There is no API key or account, and no limit on how often it runs. Above that, a commercial license is needed. See Pricing.

What happens when my app passes 10,000 monthly active devices?

Nothing breaks: Moji keeps working and never checks in with a server. You have 30 days to get a commercial license. Email raju348636@gmail.com or call / WhatsApp +91 63533 21951.

Can you build a model for my app?

Yes. Hoverfly trains custom on-device models for your language, domain or task and ships them as a small library like this one. Get in touch on the same email or number.

Why Moji

Built for a keyboard, not a datacenter

Everything runs in-process, in plain Kotlin — no runtime to bundle, no round trip to wait on.

📦

No dependencies

Pure Kotlin inference — no ONNX Runtime, no TFLite, no native code. Adds about 5 MB to your APK.

🔒

Private & offline

The model ships inside the AAR. No network calls, no permissions, no telemetry, ever.

⚡

Fast

~0.5 ms per suggestion once warm on Apple silicon, ~2 ms on a mid-range phone. Fast enough for every keystroke.

🌍

22+ languages

Trained across languages and scripts, with parity-tested output against a Python reference implementation.

}
Usage

Three lines to suggestions

Load once, reuse the instance, and call suggestions() on every keystroke — it's thread-safe and fast enough for it.

Kotlin
val moji = Moji(context)

val top = moji.suggestions("Pay my bills")
top.first().emoji        // "💰"
top.first().name         // "money bag"
top.first().confidence   // 0.36

moji.suggestions(
    "Great job thumbs up",
    limit = 5,
    skinTone = SkinTone.MEDIUM
)

moji.close()
Java
try (Moji moji = new Moji(context)) {
    List<MojiSuggestion> s =
        moji.suggestions("Pay my bills");
}
Use cases

Where Moji fits

Anywhere text is composed, one call turns it into an emoji rail — no server, no delay.

⌨️

Custom keyboards & IMEs

Power a live emoji suggestion bar above the keyboard, updated on every keystroke without leaving the device.

💬

Chat & messaging apps

Suggest reactions or inline emoji as a user types a message, the way modern chat apps auto-complete tone.

📝

Social & caption composers

Recommend emoji for post captions and status updates while the user is still writing them.

🤖

Support & chatbot UIs

Give automated responses a quick, on-brand emoji reaction without a round trip to a moderation or NLP service.

🗒️

Notes & journaling apps

Tag entries with a mood or topic emoji automatically, useful for journal timelines and mood tracking.

🛍️

Reviews & feedback forms

Turn free-text reviews into a quick emoji sentiment tag alongside the star rating, computed on-device.

🔔

Notifications & quick replies

Offer emoji-only quick-reply chips generated from the incoming notification text.

♿

Accessibility & low-effort input

Let users express a full thought with a single tap on a suggested emoji instead of typing it out.

Reference

API at a glance

MemberDescription
Moji(context)Loads the bundled model. Implements Closeable.
suggestions(text, limit = 8, skinTone = null)Best emoji first. Returns List<MojiSuggestion>.
MojiSuggestion(emoji, name, confidence, supportsSkinTone)One ranked result.
SkinTone.LIGHT … DARKApplied to people/hand emoji that support it. applyTo(emoji) is also public.
